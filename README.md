# ToDoList
A simple and modern To-Do List Web Application built using HTML, CSS, and JavaScript. This project allows users to add tasks, mark them as completed, and remove tasks when they are no longer needed.

Features
Add new tasks
Mark tasks as completed
Remove individual tasks
Dynamic task creation using JavaScript DOM
No page refresh required
Modern and responsive UI
Scrollable task list
Technologies Used
HTML5
CSS3
JavaScript
DOM Manipulation
How to Run
Download or clone the project.
Open the project folder.
Open index.html in your browser.
Enter a task and click Add.

How It Works

The application takes the task from the input field and uses JavaScript DOM methods like createElement(), append(), and remove() to dynamically create and manage tasks.

Each task contains:

Checkbox for completion
Task name
Remove button
